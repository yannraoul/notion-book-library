# Roadmap: Notion Book Library (Shelf)

Each entry below is a milestone with an **NBLM-x** (Notion Book Library
Milestone) identifier — real, scoped features/scope changes, in commit
order. Full detail for each milestone lives in its own `features/NBLM-x.md`
file; this file is just the index. Bugs found *after* the milestone that
introduced them has already shipped go in `CHANGELOG.md` instead
(**NBLB-y** ids), and not-yet-scoped ideas live in `BACKLOG.md`. See
`../instructions.md` for the full convention (commit message pattern, when
something is NBLM vs NBLB, etc).
